# PCM/DSD PeakMeter 1.1.0
배포일: 2026-10-23

## 변경사항

- 환경설정 탭이 여러 줄로 표시되며 넘침 화살표가 나오지 않습니다. 언어 변경 시 실제 탭 높이를 기준으로 배치를 다시 계산합니다.
- 언어·탭 전환 및 스크롤 후 안내문과 버튼에 남던 가로줄 잔상을 수정했습니다.
- 패널 디자인: 피크 경고 및 통계 영역을 숨기면 미터가 해당 공간까지 확장됩니다.
- dB 눈금: 양쪽 / 위쪽만 / 아래쪽만 표시를 선택합니다. 세로 패널에서는 회전한 축의 양옆에 대응합니다.
- 미터 색상: Peak Hold 표시 여부, RGB 색상 및 자동 색상 복귀, 하강 속도 10 / 30 / 60 / 120 dB/s를 설정합니다. 기본 속도는 30 dB/s이며 기존 0.50초 유지시간은 같습니다.
- 패널 디자인: 일시정지 시 미터 유지 옵션을 추가했습니다. 기본값은 해제이며 종전처럼 초기화됩니다. 유지 중에도 정지하면 초기화됩니다.
- 눈금/L/R 글자색만 변경할 때 기존 글꼴 크기와 홀드 모양이 유지됩니다. 글꼴 초기화는 원래 기본 메트릭과 마커 모양을 복구합니다.
- 새 옵션은 패널별로 Apply/OK 시 저장되며 테마 저장·불러오기·가져오기·내보내기에 포함됩니다.
- 언어 변경 즉시 패널 안내와 dB 눈금 행 이름이 갱신됩니다.
- 일반 탭에 제품 내부 표시 기능 검사를 추가했습니다. 검증한 R7에서 28/28을 통과했습니다.

PCM 샘플 피크·DoP 판별·DSD FAST/LPF 측정 커널은 유지하며 재생 오디오를 변경하지 않습니다.

## 설치 및 사용

권장 파일은 `foo_pcm_dsd_peakmeter_v1.1.0.fb2k-component`입니다. foobar2000 환경설정 → Components → Install에서 설치한 뒤 재시작하세요. 하나의 파일에 루트 x86 DLL과 x64/ 하위 x64 DLL이 들어 있습니다. 개별 x86/x64 패키지도 제공합니다.

편집할 패널을 선택하고 옵션 변경 후 Apply 또는 OK를 누르세요. Peak Hold 세부 옵션은 미터 색상 탭을 아래로 스크롤하면 표시됩니다. 일시정지 유지 옵션은 체크하고 적용한 뒤 재생 → 일시정지로 확인합니다.

## 호환성과 확인 범위

편집하지 않은 V1~V6 패널 레코드는 기존 인코딩을 유지하며, 편집한 설정은 V7로 저장합니다. V7을 이해하지 못하는 이전 버전으로 되돌리기 전에는 프로필을 백업하세요.

MSVC v145로 x64와 x86을 빌드했으며 패키지 내부 DLL·엔트리·PE 아키텍처를 확인했습니다. 사용자가 R7 TEST 호스트의 기능 및 한·영 설정 화면, 잔상 제거와 일시정지 유지를 확인하고 완료했습니다. 별도 x86 호스트 실행과 공식 Get updates 경로의 성공은 이번 준비 자료에서 확인되지 않았습니다.
