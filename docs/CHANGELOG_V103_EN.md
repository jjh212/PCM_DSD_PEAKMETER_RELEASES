# PCM/DSD PeakMeter v1.0.3 — Release Notes

## High-resolution and DPI improvements

- Improved Preferences UI scaling across different screen resolutions and Windows display scaling settings.
- Fixed overlapping controls, truncated text, and insufficient button widths at higher DPI settings.

- Optimized the DSD settings panel's vertical spacing to eliminate unnecessary scrolling.
- Preserved the FAST/LPF settings and filter response graph.

## Existing functionality

- PCM/DSD peak measurement and audio processing functionality remain unchanged.
