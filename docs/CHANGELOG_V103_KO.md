# PCM/DSD PeakMeter v1.0.3 — 업데이트 내역

## 고해상도 및 DPI 대응 개선

- 다양한 화면 해상도와 Windows 디스플레이 배율에 맞춰 환경설정 UI가 정상적으로 표시되도록 개선했습니다.
- 고배율 환경에서 발생하던 글자 잘림, 버튼 크기 및 컨트롤 겹침 문제를 수정했습니다.

## DSD 설정 화면 개선

- DSD 설정 화면의 세로 공간을 최적화하여 불필요한 스크롤바를 제거했습니다.
- FAST/LPF 설정 및 필터 응답 그래프의 기존 표시 기능을 유지했습니다.

## 기존 기능 유지

- PCM/DSD 피크 측정 및 오디오 처리 기능은 변경하지 않았습니다.
